Mathematics of the Recommendation System

1. Collaborative Filtering

\[ \text{similarité}(u, v) = \frac{\sum_{i=1}^{n} r_{u,i} \cdot r_{v,i}}{\sqrt{\sum_{i=1}^{n} r_{u,i}^2} \cdot \sqrt{\sum_{i=1}^{n} r_{v,i}^2}} \]

2. Content-Based Filtering

\[ \text{similarité}(a, b) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\| \cdot \|\mathbf{b}\|} \]

3. Combining Approaches

\[ \text{score final} = \alpha \cdot \text{score collaboratif} + (1 - \alpha) \cdot \text{score contenu} \]

4. Code Example


from sklearn.metrics.pairwise import cosine_similarity
import numpy as np
# Exemple de vecteurs de films (genres : Action, SF, Drame)
films = {
    "Inception": [1, 1, 0],
    "Interstellar": [0, 1, 1],
    "Titanic": [0, 0, 1]
}
# Calcul de la matrice de similarité
vecteurs = np.array(list(films.values()))
similarite = cosine_similarity(vecteurs)
# Recommandations pour "Inception"
film_index = 0  # Index de "Inception"
recommandations = sorted(
    [(list(films.keys())[i], similarite[film_index][i])
     for i in range(len(films)) if i != film_index],
    key=lambda x: x[1],
    reverse=True
)
print("Recommandations pour Inception :", recommandations)
